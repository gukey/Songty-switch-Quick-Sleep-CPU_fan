# 窗口归集回归检查

在 Windows 多屏扩展桌面上运行，需要 .NET 10 SDK。

```powershell
dotnet run --project tests/WindowCheck/WindowCheck.csproj -c Release
```

测试创建自己的普通、最大化和最小化窗口，在主副屏之间移动这些测试窗口，然后核验归位结果。包含「无历史快照时将全部测试窗口归集到主屏」以及「最小化窗口重新打开后仍在主屏」检查。不会切换真实显示拓扑，也不会移动其他应用窗口。

默认使用临时目录保存测试配置。运行期间会短暂显示测试窗口与快捷键编辑对话框；完成后自动关闭。原生窗口恢复有约 12 秒的稳定性检查，整个测试通常需要半分钟。
